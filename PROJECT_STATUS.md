# Project Status — Survival Companion

**Portfolio class:** Engineering lab / edge application  
**Maturity:** **Software prototype with hardware integration pending**

This Raspberry Pi/edge-compute project explored an offline field companion combining reference information, GPS/environmental inputs, vision, voice and local AI concepts.

## Evidence boundary

A key positive in this repository is the explicit removal of fake/simulated sensor readings: unavailable hardware should report **not available** rather than inventing data. That evidence discipline should be preserved.

The project should not be represented as a validated medical, rescue or safety device. Medical/reference material requires independent professional review, and hardware-dependent features should only be claimed where tested.

**Portfolio use:** evidence of edge-AI architecture and increasingly rigorous separation between implemented, simulated and hardware-pending capabilities.
